## Cómo correr el proyecto
1. Instalar dependencias: `pip install -r requirements.txt`
2. Abrir la carpeta `entrega/` con Jupyter.
3. Ejecutar en este orden:
   - `fase_a_eda.ipynb` (lee el CSV original)
   - `fase_b_limpieza.ipynb` (genera `datos_limpios.parquet`)
   - `fase_c_modelos.ipynb` (lee el parquet y entrena los modelos)
